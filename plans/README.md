# Directorio de Planes, Especificaciones y Tareas (`plans/`)

Este directorio contiene los planes de desarrollo de funcionalidades para **EternalIA**, regido de forma mandatoria por el **[ADR-0003](../adr/0003-planes-especificaciones-tareas-unificados.md)**.

---

## 🎯 Principio Fundamental: 3-en-1
Para evitar fragmentación documental y alucinaciones en el desarrollo asistido por IA, **cada funcionalidad posee un único archivo consolidado** que integra:
1. **Plan de Implementación:** Arquitectura, alcance, justificación y riesgos.
2. **Especificaciones Técnicas y Funcionales:** Requerimientos de producto, diseño Dark/Light (ADR-0002), contratos de API y criterios de aceptación.
3. **Lista de Tareas Accionables:** Checklist interactivo (`[ ]` / `[x]`) con fases secuenciales de ejecución.

---

## 📋 Convención de Nomenclatura
- Formato: `XXXX-nombre-de-la-funcionalidad.md` o `YYYYMMDD-nombre-de-la-funcionalidad.md`
- Plantilla estándar: [`TEMPLATE.md`](./TEMPLATE.md)
