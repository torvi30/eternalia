# Eternalia • Holding Tecnológico & Ecosistema SaaS

Plataforma corporativa oficial de **Eternalia**, el holding tecnológico que unifica soluciones SaaS, vitrinas digitales de alta conversión, redes de servicios profesionales y software vertical para industrias críticas.

---

## ⚡ Tecnologías & Stack

- **Framework:** React 18 + Vite
- **Estilos:** Tailwind CSS 3.4 (Dark Mode estilo Silicon Valley / Linear / Vercel)
- **Iconografía:** Lucide React
- **Fuentes:** Plus Jakarta Sans & JetBrains Mono (Google Fonts)
- **Internacionalización:** Sistema dinámico bilingüe (Español / Inglés) con persistencia en `localStorage`

---

## 🏛️ Arquitectura del Holding

1. **Eternalia Commerce Cloud:** Frontends de alta velocidad, Landing Pages de ultra-alta conversión, catálogos digitales interactivos con QR y checkout sin intermediarios.
2. **Eternalia Services Infrastructure (Workforce OS):** Plataforma para la formalización y escalamiento de la economía de servicios independientes con identidad verificada, split payments y garantías digitales.
3. **Eternalia Enterprise Ventures:** Soluciones de software de misión crítica (Telemetría satelital IoT para flotas pesadas, ERP masivo para eventos de alta hostelería y movilidad digital).
4. **Red Comercial Inteligente (Hyperlocal Mesh):** Malla de descubrimiento georreferenciado para interconectar municipios comerciales sin comisiones abusivas y con enlace directo a WhatsApp.

---

## 🚀 Instalación y Despliegue Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/torvi30/eternalia.git
cd eternalia

# 2. Instalar dependencias
npm install

# 3. Iniciar el servidor de desarrollo
npm run dev

# 4. Compilar para producción
npm run build
```
